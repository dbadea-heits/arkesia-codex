Pre-Ark-Grid Mayhem for Solo Mode and party raids. This is the older Sword Storm + Power Break build from the guide that preceded the Technique card, not the newer Sound Breakthrough / Brave Slash guide.
The code is a KR build imported to CE; whether it plays identically on global depends on global having the same Berserker balance patch.

Use the pre-grid build with a Crit/Swiftness split, Swiftness pet and a Crit/Swiftness bracelet. The author targets about 60% displayed town Crit.

## How it plays

- Maintain Mayhem, then use ![Red Dust](assets/icons/berserker/red-dust.png) Red Dust to create the damage window.
- Fit ![Blood Slash](assets/icons/berserker/blood-slash.png) Blood Slash when available, then ![Overdrive](assets/icons/berserker/overdrive.png) Overdrive → ![Finish Strike](assets/icons/berserker/finish-strike.png) Finish Strike → ![Hell Blade](assets/icons/berserker/hell-blade.png) Hell Blade → ![Sword Storm](assets/icons/berserker/sword-storm.png) Sword Storm → ![Power Break](assets/icons/berserker/power-break.png) Power Break.
- Follow with ![Mountain Crash](assets/icons/berserker/mountain-crash.png) Mountain Crash twice. ![Dark Rush](assets/icons/berserker/dark-rush.png) Dark Rush is for push immunity and stagger, not the damage loop.
- The author notes that Dark Rush should be inserted inside Red Dust when it returns and that the 2025-12 post's sequence is Red Dust → hyper awakening when available → Overdrive / Finish Strike / Hell Blade → Sword Storm → Power Break → Mountain Crash ×2.

## Setup

- **Engravings:** Grudge, Keen Blunt Weapon, Raid Captain, Cursed Doll and Master's Tenacity. Replace Keen Blunt Weapon with Mass Increase if the bracelet supplies attack speed.
- **Stats and Ark Passive:** Crit 18 / Swiftness 22 in the imported Evolution tree. The author uses a Swiftness pet, a Crit/Swiftness bracelet and approximately 60% displayed town Crit.
- **Skills:** ![Red Dust](assets/icons/berserker/red-dust.png) Red Dust 11; ![Mountain Crash](assets/icons/berserker/mountain-crash.png) Mountain Crash 14; ![Finish Strike](assets/icons/berserker/finish-strike.png) Finish Strike 14; ![Overdrive](assets/icons/berserker/overdrive.png) Overdrive 14; ![Hell Blade](assets/icons/berserker/hell-blade.png) Hell Blade 14; ![Sword Storm](assets/icons/berserker/sword-storm.png) Sword Storm 14; ![Power Break](assets/icons/berserker/power-break.png) Power Break 14; ![Shoulder Charge](assets/icons/berserker/shoulder-charge.png) Shoulder Charge 1.
- **Runes:** The code carries runes on all 7 leveled skills. The source assigns Bleed to Red Dust and Overdrive, Quick Recharge to Mountain Crash and Shoulder Charge, Galewind to Finish Strike, Hell Blade and Power Break, and Focus to Sword Storm.
