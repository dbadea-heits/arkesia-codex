# Guardian Knight: Solo Mode, 1640, no Ark Grid

**Brief:** Guardian Knight, Solo Mode, item level 1640, no Ark Grid cores. Spec defaults to Dread Roar, which is effectively tied with Hellfire Successor on loagg (796 vs 785 players).

No Guardian Knight code made for Solo Mode, or for no Ark Grid, has been posted since KR's 2026-04-22 balance patch. The scraper checked all 1,917 posts on the Inven Guardian Knight board. One reply on that board ([post 7553](https://www.inven.co.kr/board/lostark/6469/7553), 2026-10-07) says that with no cores you should use the 333 tree. Both codes below are party builds.

## Caveats

- **Solo Mode:** you get no support buffs, so cycles that assume a support's attack-speed buff run a bit slower.
- **Global:** both codes are KR and untested on global. They're only safe if global already has KR's 2026-04-22 balance patch; that's unconfirmed.
- **Verification:** both codes were pulled straight from the post HTML and re-checked against the live pages.
- **Name matching:** Keen Blunt Weapon isn't ID-matched because the codex lookup timed out. The other engravings, and all skill and rune names, are ID-matched on lostarkcodex.com. The spec names Dread Roar and Hellfire Successor come from Maxroll and community usage.
- **333:** a KR nickname for running three Order cores of the same type. It doesn't apply until you have the Ark Grid.
