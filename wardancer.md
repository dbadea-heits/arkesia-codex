# First Intention Wardancer: Solo Mode at 1640 (pre-grid)

**Brief:** Wardancer, First Intention (KR 초심), Solo Mode raids (KR 싱글모드), item level 1640, no Ark Grid cores, region CE. First Intention is loagg's default spec: 776 players vs 206 for Esoteric Skill Enhancement (KR 오의 강화), 1720+ sample, updated 2026-09-17.

No source posts a code made for Solo Mode. The pick is a party-raid code made explicitly for **before the Ark Grid** (1680–1700); nothing closer exists. Jev pick probability 0.77, but its fit to every brief field is only 0.09 because it isn't a Solo Mode code.

Skill, tripod, rune, engraving and Ark Passive names are global client names, matched to the KR names by game ID through lostarkcodex.com (US vs KR locale) and lostark.bible. Icons in `assets/icons/battlemaster/` come from lostarkcodex.com, converted to 32px PNG. Both codes were checked on [lostark.bible](https://lostark.bible/tools/skill-code) and are stored on CE (the pick was uploaded to CE on 2026-10-20). Whether they play the same on global depends on global having KR's balance patches, which is unverified. The last KR patch to touch First Intention was 2026-04-22; both later patches (2026-06-24, 2026-07-22) only changed Esoteric Skill Enhancement and the Ark Grid cores.

### Setup notes (author)

- **Gem order:** ![Sweeping Kick](assets/icons/battlemaster/sweeping-kick.png) Sweeping Kick → ![Leaping Dragon](assets/icons/battlemaster/leaping-dragon.png) Leaping Dragon → ![Energy Combustion](assets/icons/battlemaster/energy-combustion.png) Energy Combustion → ![Flash Heat Fang](assets/icons/battlemaster/flash-heat-fang.png) Flash Heat Fang, highest gems first (e.g. Sweeping Kick Blaze 9 / Doom 8, Leaping Dragon Blaze / Doom 8).
- **Z (identity):** use it early so it automatically empowers the strongest skill of the next cycle. During the Wind's Whisper buff you can bend the cycle to put the empowerment on ![Deadly Dive](assets/icons/battlemaster/deadly-dive.png) Deadly Dive or ![Sweeping Kick](assets/icons/battlemaster/sweeping-kick.png) Sweeping Kick.
- **Without the Ark Grid every skill fills 0.2 of a Z bubble.** The 초순환 core (KR nickname for the Order Moon core; no global name checked) later refills a full bubble on Roar of Courage / Wind's Whisper. The author says the cycle is much harder before cores than after.
- **Once you reach 1700 and fill the Order cores,** re-spec the Ark Passive to taste ([author's Ark Passive video](https://youtu.be/K5k4PpwySO0)).

### Pre-grid base setting from the certified Inven guide

The [certified First Intention guide](https://www.inven.co.kr/board/lostark/5342/136345) (updated 2026-04-22, 954 comments, no code) gives a "base setting" for before the Ark Grid. Same engravings as the pick; it differs in:

- **Evolution:** Crit 10 / Swiftness 30; Illicit Spell 2, Limit Break 1; Unlimited Magick 1, Strike 1; Critical 1, Pulverize 1; Supersonic Breakthrough 2.
- **Tripods** (only where they differ from the pick):

  | Skill | Pick | Inven base |
  |---|---|---|
  | ![Sweeping Kick](assets/icons/battlemaster/sweeping-kick.png) Sweeping Kick | Weak Point Detection, Light of Justice, Pure Excellence | Weak Point Detection, Intense Shock, Pure Excellence |
  | ![Leaping Dragon](assets/icons/battlemaster/leaping-dragon.png) Leaping Dragon | Concussion, Dragon Style, Red Dragon | Wide Hit, Dragon's Teeth, Red Dragon |
  | ![Flash Heat Fang](assets/icons/battlemaster/flash-heat-fang.png) Flash Heat Fang | Concussion, Master Hit, Final Strike | Wide Hit, Master Hit, Final Strike (Magick Control in tier 1 if mana runs dry) |
  | ![Sky Shattering Blow](assets/icons/battlemaster/sky-shattering-blow.png) Sky Shattering Blow | Excellent Mobility, Ready Attack | either that or Swift Footwork, Ready Attack |

  The guide switches Sweeping Kick to Light of Justice and Leaping Dragon to Dragon Style once you use the Order Star core 용류강화 (KR nickname; global name not checked). The pick already uses those two tripods.
- **Basic cycle:** ![Roar of Courage](assets/icons/battlemaster/roar-of-courage.png) Roar of Courage → ![Wind's Whisper](assets/icons/battlemaster/wind-s-whisper.png) Wind's Whisper → ![Lightning Kick](assets/icons/battlemaster/lightning-kick.png) Lightning Kick → ![Deadly Dive](assets/icons/battlemaster/deadly-dive.png) Deadly Dive → ![Sweeping Kick](assets/icons/battlemaster/sweeping-kick.png) Sweeping Kick → ![Leaping Dragon](assets/icons/battlemaster/leaping-dragon.png) Leaping Dragon → ![Flash Heat Fang](assets/icons/battlemaster/flash-heat-fang.png) Flash Heat Fang → ![Lightning Kick](assets/icons/battlemaster/lightning-kick.png) Lightning Kick (Roar / Whisper order doesn't matter). Use Z as soon as it has 3 bubbles. Detonate ![Energy Combustion](assets/icons/battlemaster/energy-combustion.png) Energy Combustion on cooldown, ideally while the Wind's Whisper buff is up.
- **When you have to move to the boss:** Roar → Whisper → Lightning Kick → ![Sky Shattering Blow](assets/icons/battlemaster/sky-shattering-blow.png) Sky Shattering Blow → Lightning Kick → Flash Heat Fang (so nothing sits off cooldown) → move → Deadly Dive → Sweeping Kick.
- **If the boss disappears:** pre-cast Roar → Whisper, then on reappearance Lightning Kick → Deadly Dive → Sweeping Kick → Leaping Dragon → Flash Heat Fang → Lightning Kick.
